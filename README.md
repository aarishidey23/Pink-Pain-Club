🎀 Installation

1. Clone the repository

git clone https://github.com/aarishidey23/Pink-Pain-Club.git

2. Enter the project

cd Pink-Pain-Club

3. Install the dependencies

npm install

4. Start the dev server

npm run dev

Open the local URL shown in your terminal and let her shine. 💅🏻

✨ Build for production

npm run build

💖 Preview the production build

npm run preview

🩷 WHY PINK PAIN CLUB?

Period wellness deserves more than awkward conversations and being told to simply deal with it.

Pink Pain Club aims to make menstrual health information feel approachable, supportive, and easier to explore — without making anyone feel embarrassed about their body.

Because periods are natural. Pain deserves attention. And every girl deserves care. 💋

⚕️ A LITTLE HEALTH REMINDER

Pink Pain Club provides general menstrual wellness information and is not a substitute for professional medical advice, diagnosis, or treatment.

If your pain is severe, sudden, unusual, or persistent, please speak with a qualified healthcare professional. You deserve proper care, always. 🫶
